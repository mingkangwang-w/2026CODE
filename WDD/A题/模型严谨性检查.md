## 一、代码级硬伤（直接削弱论文可信度）

### 1. Picard 迭代实为“空转”，非线性耦合从未真正迭代 —— 严重

`solver.py:161-173` 中 `Ti, Ci = T, C` 只在 `for` 循环**外**赋值一次，循环体内 `T`、`C` 被更新但 `Ti/Ci` 不再刷新：

```python
def _step_implicit(...):
    Ti, Ci = T, C              # 只在循环外
    for _ in range(max(1, picard)):
        rc = props.rho(Ci)*props.cp(Ci)              # 始终用旧 Ci
        kf, Df = _iface(props.k(Ci)), _iface(props.D(Ci, Ti))  # 始终用旧 Ti/Ci
        T = _solve_tri(..., Ti + ...)
        C = _solve_tri(..., Ci + ...)
    return T, C
```

由于 `rc/kf/Df` 只依赖 `Ti,Ci`（循环内不变），两次循环求解的是**同一个线性方程组**，第二次迭代纯冗余。实际只是“单步滞后线性化”（半隐式），**并未实现文档所宣称的“Picard 迭代至 ‖ΔT‖<1e-6、‖ΔC‖<1e-8”**（`建模方案_合并版.md:97`）。

- 后果：在 dt=10 s 下因物性变化缓慢而很小（dt 收敛 0.004%），但论文里“耦合迭代收敛”的表述与代码不符，评审较真时是硬伤。
- **修复**：把 `Ti, Ci = T, C` 移进循环体顶部，使每轮线性化基于最新迭代值。

### 2. “水分质量守恒”校验收的是错误物理量 —— 严重

`solver.py:140` 的 `mass_series = ∑ C·x·dx` 是 **∫C dV**（干基 C 对体积积分），而 `run_q1/q2/q3` 的守恒校验（如 `run_q3.py:84-87`）正是用这个量 + 表面通量 `h_m(C_s-C_∞)` 做的。文档自己在 `建模方案_合并版.md:114` 已写清：

> 干基 C + 变密度下，域内水分总量 = **∫ρC/(1+C)dV**（不是 ∫ρC dV）

但代码并未按此执行。两层含义：

- 实际校的是“干基 C 体积积分的守恒”，由 FV 格式**天然保证**，几乎不构成独立验证（偏套套逻辑）；
- 真正的水分质量守恒（含变密度 ρ(C)）根本没被验证。

论文若把这条写为“水分质量守恒 <1%”属于**名不副实**。

### 3. 问题 4 动域恒等式残差 1.5% > 声称的 <1% —— 中

`q4_summary.json` 的 `moving_mass_identity_rel_resid = 0.0152`，超过 `HC-13` 的 “<1%”。代码注释虽承认“迎风一阶，允许 O(1/N)”，但文档/硬约束仍写 <1%。建议：

- 将伪对流项换成中心差分（二阶），或按 N=161 重算并诚实报出随 N 的收敛；
- 不留与判据矛盾的数字。

## 二、物理/数学严谨性问题

### 4. 质量方程丢掉干物质密度累积项（∂C/∂t vs ∂(ρ_s C)/∂t）

能量方程用了 `ρ(C)c_p(C)∂T/∂t`（正确计入变密度），但质量方程写 `∂C/∂t = ∇·(D∇C)`，没有干物质密度因子。附录 3 中 ρ 变化 40%~90%，严格的水分质量守恒应为：

$$\frac{\partial(\rho_s C)}{\partial t}=\nabla\cdot(\rho_s D\,\nabla C),\qquad \rho_s=\frac{\rho}{1+C}$$

这是文献里常见的“Fick 第二定律简化”，但**必须作为显式模型假设写进论文**（尤其 Q4 收缩域下干物质密度随体积变化，该省略会在守恒层面留下缺口），否则与能量方程的变密度处理构成内部不一致。目前文档只在边界条件量纲处（`建模方案_合并版.md:33`）点了一句，未覆盖累积项。

### 5. ln(MR) 渐近线“同量级”的说法偏乐观 —— 中

`q3_summary.json`：由斜率反推 `D_eff=5.87e-10`，而对照取 `D(C=0.2,T=50°C)=1.69e-9`，差 **2.9 倍**，用“同一量级”一笔带过偏勉强。

- 实际末期 C∈[0.15,0.2]，`D(C=0.15,T=50)≈7.9e-10` 更接近提取值，说明方向是对的；
- **建议**：对照值改用末期 C 的真实区间（0.15~0.2）而非 C=0.2 单点，并交代 `Bi_m` 有限导致首根 β<2.405 的修正。

### 6. 问题 1 半解析“D(C) 变化 <5%”是错的 —— 低（结论仍可用）

`analytic.py:7` 称 Q1 中 `D(C)` 变化 <5%，实际 `D(2.55)=4.94e-9` → `D(1.51)=3.88e-9`，约 **21%**。之所以半解析仍吻合（C 误差 0.042 kg/kg ≈ 1.6%）是因为扩散渗透深度仅 ~0.3 cm、偏离集中在极薄表层。**理由写错但结果成立**，需修正该 justification 措辞。

### 7. 一维“端面效应 <5%”是估算未实证 —— 低

`HC-22` 要求给出量化依据与敏感性对照，但代码**从未做二维轴对称对照**，“<5%”只是 `L/(2R0)=6.25` 的量级推断。建议：补一个二维对照算例，或在论文中明确标注为“量级估算”。
