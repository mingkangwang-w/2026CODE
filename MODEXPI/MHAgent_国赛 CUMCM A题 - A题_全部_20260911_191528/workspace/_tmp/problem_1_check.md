## 约束与能力校验（全部硬断言，越界即 raise）

- B-19 数值有限：通过。
- B-10 物理界限：C ∈ [1.5104, 2.55] ⊂ [0, C0]；T ∈ [27, T_inf,max+1]。
- B-11 单调性：`max_r diff(C) ≤ 1e-12`，沿 r 非增。
- bd_center_is_wettest：`max_r C - C[0] = 0`，违例计数 0。判据改为舍入鲁棒的
  center_deficit（裸 argmax 在初值均匀时由 ~1e-16 噪声决定，会指向任意内部节点，
  不具判别力；边界符号写错会使表面比中心湿 O(0.1)，仍被此形式否证）。
- B-04 常物性：`ptp(rho)=ptp(cp)=ptp(k)=0`。
- B-12 质量守恒：**eps_M = 4.285e-14**（限 0.01）。隐式时刻累计 Q 使离散守恒成为恒等式，
  故残差在机器精度量级而非 O(Δt)。
- B-06 Robin 通量残差：温度 1.05e-6（< 1e-3，报告判据写在温度上）。
  水分 1.35e-3，取限 1e-2 并附收敛验证：N=40/80/160/320 残差
  4.32e-3 → 1.35e-3 → 3.82e-4 → 1.02e-4，阶 1.68 → 1.82 → 1.91，
  确认是三点重建的 O(δ²) 截断（水分边界层薄于一个网格），非通量表达式错误；
  同时 C_surf 收敛到 1.51026，与报告 1.5104 一致。
- B-09 中心对称：`|grad_center| / |grad_surface|` 两场均 < 1e-2。
- B-23 / B-29 / P1-C4：表 1/2 时刻标签与题面一致；result1.xlsx 双表
  `['温度','水分浓度']`，A1 = `时间\到药材中心的距离`，21 列、步长 1 s。
- P1-C1：D 写成分式指数 `exp(-0.89/C)`（源码字符串可静态扫描）；
  附录 2 常物性 (820, 2600, 0.36) 逐项核对。
- P1-C3 行数：**1801 行**，t = 0 → 1800 s，步长 1 s。附件 3 模板首数据行为 t=1，
  而 P1-C3 明文要求"0 到 1800 步长 1 s（1801 行）"；取 1801 行（含 t=0）以满足
  能力项，步长仍守模板的 1 s。此偏离将写入 RESULTS.md。
- bd_q1_analytic_gap：**0.0021 K**（报告 0.0031，容差 0.007）。独立通道为
  Bessel 特征展开 + Duhamel 叠加，2000 阶模态，`|Σ A_n - 1| < 1e-5`，
  对分段线性 T_inf(t) 逐模态精确递推（无时间离散误差），不借用数值解。
- 显式小步长交叉验证：偏差 T = 0.0004 K、C = 2.99e-5。
  B-18 的 dr²/(2Γ) 是内部节点的经典界；r=0 半控制体权重 δ²/8 使真实稳定界紧一倍，
  故另算算子行和界并取较小值（`operator_row_bound_dt`），否则显式通道溢出。
